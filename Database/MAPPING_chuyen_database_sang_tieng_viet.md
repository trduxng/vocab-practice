# Mapping chuyển database sang tiếng Việt

Nguồn mapping dùng để đổi tên vật lý database, đồng bộ backend và frontend. Quy tắc: tiếng Việt không dấu, PascalCase cho database object; giữ các chuẩn kỹ thuật như `ID`, `URL`, `JSON`, `API`, `JWT`, `HTTP`, `Email`, `Hash`, `UK`, `US`, `TOEIC`, `Client`, `dbo`, và prefix `PK_`, `FK_`, `UQ_`, `CK_`, `DF_`, `IX_`, `vw_`, `usp_`.

## 3. Backend/frontend guideline

- Backend entity/class nên dùng tên mới tương ứng với table mới, ví dụ `NguoiDung`, `ChuDe`, `TuVung`.
- Backend field nên dùng camelCase từ tên database mới, ví dụ `nguoiDungID`, `hoTen`, `trangThaiNoiDung`.
- Frontend key nên theo backend field mới; label UI dùng tiếng Việt có dấu, ví dụ `hoTen` -> `Họ tên`.
- Permission check phải đổi từ mã cũ sang mã mới, ví dụ `MANAGE_WORDS` -> `QUAN_LY_TU_VUNG`.
- API contract cũ sẽ vỡ nếu đang trả trực tiếp tên field tiếng Anh; cần update parser/type/interface đồng bộ.
